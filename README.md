# 🔴 Зеленое кольцо Москвы — Виджет для Twitch / OBS Studio (IRL Stream)

Полностью автономный веб-виджет для стримов по **Зеленому кольцу Москвы (ЗКМ)**.
Виджет отображает круговой маршрут на основе карты `public/map.png`, перемещает кепку-маркер `public/cap.png` вдоль парков по живому GPS стримера, рассчитывает скорость и выводит текущий пульс (BPM) в реальном времени.

---

## ⚡ Особенности виджета

- **100% прозрачный фон**: готов к добавлению в OBS поверх стрима (разрешение — **1920×1080**).
- **Локальная карта**: работает только с `public/map.png` и `public/cap.png`. **Никаких платных API Google Maps, Яндекс.Карт или подписок.**
- **Красная кепка-маркер**: плавное скольжение по кольцу на 60 FPS через интерполяцию (`LERP`) с пульсирующим радаром.
- **Компактный HUD сверху**:
  - `SPEED 0.0 км/ч` — скорость по GPS с фильтрацией погрешности и сглаживанием.
  - `❤️ 0 BPM` — динамическая частота биения сердца, привязанная к пульсу.
  - Название текущего парка (24 калиброванных парка Москвы) и шкала прогресса кольца (0–100% от 160 км).
  - При потере GPS сигнала позиция не сбрасывается: кепка остается на последней точке.
- **Интеграция с Redmi Watch 6 и Bluetooth-пульсометрами**:
  - Web Bluetooth (GATT Heart Rate 0x180D).
  - Функция «Трансляция пульса» в часах Redmi.
  - WebSocket и открытый REST API (`/api/bpm`, `/api/gps`, `/api/update`).

---

## 🚀 1. Запуск сервера

В папке проекта выполните:

```bash
npm start
```

Сервер запустится на порту `3000`.

---

## 🎥 2. Добавление в OBS Studio

1. В OBS добавьте источник **Браузер (Browser Source)**.
2. Настройки источника:
   - **URL**: `http://localhost:3000/?clean=1`
   - **Ширина**: `1920`
   - **Высота**: `1080`
   - **Пользовательский CSS**: очистить (оставить пустым).
   - Поставьте галочку **«Обновлять браузер, когда сцена становится активной»**.

---

## 📱 3. Как стримеру из Moblin всё передать в OBS

Стример находится на улице в Москве с телефоном (Moblin) и часами Redmi Watch 6, а вы ведёте трансляцию на компьютере.

### Вариант 1 (Рекомендуемый и самый надежный):
Стример в **Moblin** транслирует только видео и звук (через SRT / RTMP на ваш OBS/сервер), а GPS и Пульс передаёт через страницу-пульт:

1. **Дайте серверу публичный интернет-доступ**:
   Поскольку стример находится на мобильном интернете 4G/LTE, ему нужен доступ к вашему локальному серверу.
   Запустите бесплатный туннель Cloudflare (без регистрации):
   ```bash
   npx -y cloudflared tunnel --url http://localhost:3000
   ```
   Либо разместите проект на вашем VPS. Вы получите публичную ссылку, например:
   `https://xxxx.trycloudflare.com`

2. **Стример открывает пульт на телефоне**:
   Стример в браузере Safari/Chrome на телефоне переходит по ссылке:
   ```text
   https://xxxx.trycloudflare.com/mobile
   ```
3. **Стример нажимает «🛰️ НАЧАТЬ ТРАНСЛЯЦИЮ GPS»**:
   - Телефон сразу начинает отправлять точные координаты и скорость в ваш OBS по защищенному WebSocket.
   - Экран телефона блокируется от засыпания (Wake Lock).
4. **Стример подключает пульс с Redmi Watch 6**:
   - На часах запускается любая тренировка (например, «Ходьба»).
   - В настройках тренировки включается **«Трансляция пульса» (Heart Rate Broadcast)**.
   - На странице `/mobile` стример нажимает кнопку **«🔗 ПОДКЛЮЧИТЬ ЧАСЫ REDMI WATCH 6»** и выбирает часы.
   - Пульс начинает поступать в ваш OBS в реальном времени!

---

### Вариант 2 (Виджет прямо внутри Moblin на телефоне):
В приложении Moblin есть встроенный браузерный виджет (**Settings** ➔ **Scenes** ➔ **Widgets** ➔ **Browser**):

1. Вставьте публичный URL виджета:
   `https://xxxx.trycloudflare.com/?clean=1`
2. Moblin отобразит круговую карту и HUD прямо поверх камеры на телефоне и передаст в готовом видеопотоке SRT в ваш OBS.
3. В настройках Moblin (**Settings** ➔ **Workout device** ➔ **Heart rate**) подключите часы Redmi Watch 6 (с включенной функцией «Трансляция пульса»).

## 📡 4. Прямой REST API (для сторонних приложений)

Если стример использует сторонние приложения трекинга (OsmAnd, Traccar, Tasker, Pulsoid, HypeRate), они могут отправлять данные простыми HTTP-запросами:

- **Отправить GPS и Пульс вместе:**
  ```bash
  POST http://ВАШ_СЕРВЕР:3000/api/update
  Content-Type: application/json
  {"lat": 55.782, "lon": 37.785, "speed": 9.5, "bpm": 138}
  ```
- **Отправить только пульс:**
  ```bash
  POST http://ВАШ_СЕРВЕР:3000/api/bpm
  Content-Type: application/json
  {"bpm": 142}
  ```
- **GET запрос:**
  ```text
  http://ВАШ_СЕРВЕР:3000/api/bpm?val=142
  ```
